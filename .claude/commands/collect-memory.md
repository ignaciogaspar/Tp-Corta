# /collect-memory

Actualiza la memoria del agente para este repositorio.

## Objetivo

Revisá la conversación actual y el estado del repo, y actualizá `AGENTS.md` con:
- los milestones hechos y el estado actual,
- decisiones relevantes tomadas en la conversación,
- convenciones del equipo,
- instrucciones operativas que deban seguir los próximos agentes,
- cambios pendientes o riesgos conocidos.

## Instrucciones

1. Lee la conversación reciente del agente y el contenido actual del repo.
2. Identificá qué milestones ya están resueltos, qué queda pendiente y qué decisiones concretas se tomaron.
3. Actualizá `AGENTS.md` conservando la estructura existente y agregando lo nuevo sin borrar reglas relevantes.
4. Mantén la memoria breve, útil y accionable.
5. No guardes secretos ni credenciales. Solo documentá configuración y decisiones relevantes del proyecto.
6. Si el repo cambió de estado, reflejalo en la sección "Estado actual".
7. Si se definieron preferencias del equipo (estilos, convenciones, tareas programadas, uso de Railway, testing, etc.), registralas en la sección correspondiente.

## Resultado esperado

`AGENTS.md` queda actualizado con el último contexto operativo del proyecto para la próxima sesión.
